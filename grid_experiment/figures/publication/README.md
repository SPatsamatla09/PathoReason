# Publication figures

Generated by `grid_experiment/make_publication_figures.py` from the corrected
full-MHIST Track-A outputs and the completed cross-dataset comparison.

## Suggested combined caption

**Figure X. Track-A performance and perturbation-based faithfulness results.**
(A) Receiver operating characteristic curve for the original PLIP Track-A
predictions on 977 MHIST test images (AUC = 0.729); this panel reports baseline
classification discrimination, not explanation faithfulness. (B) Image-level
original-class probability drops after removal of GPT-4o-cited cells and after
tissue-matched random-cell removal. (C) Feature-specific control-adjusted
effects (cited-removal drop minus matched-control drop) with image-clustered
bootstrap 95% confidence intervals. Only features meeting the prespecified
minimum of five images are shown. (D) Image-level control-adjusted effects for
MHIST (n = 977) and PatchCamelyon (n = 20), with bootstrap 95% confidence
intervals. Positive values indicate that cited-cell removal caused a larger
drop than matched-control removal; negative values indicate that the matched
control caused the larger drop.

## Interpretation guardrails

- The ROC curve must not be described as a measure of explanation faithfulness.
- Negative control-adjusted effects do not invalidate the experiment. They mean
  the cited regions did not outperform tissue-matched random regions under the
  corresponding perturbation.
- PatchCamelyon has only 20 images, so the cross-dataset confidence intervals
  are substantially wider than MHIST's.
- The per-feature panel excludes features with fewer than five independent
  images from inferential display; those features may still be reported as
  descriptive results if clearly labeled.
